# C722 OA Focus & Must-Know Topics

## Core Distinctions
- Project vs. operation vs. program vs. portfolio  
- Temporary vs. ongoing work  
- Unique deliverable vs. repetitive tasks  
- Frequently tested in scenario questions

## Project Life Cycle
- Defining/Initiating  
- Planning  
- Executing  
- Monitoring & Controlling  
- Closing  
- Know which activities belong to which phase (charter, WBS, schedule, lessons learned)

## Triple Constraint
- Scope  
- Time (schedule)  
- Cost  
- How changing one affects the others  
- Common OA scenario topic

## Organizational Structures
- Functional  
- Weak matrix  
- Balanced matrix  
- Strong matrix  
- Projectized  
- PM authority levels and resource control

## PMO & Governance
- Benefits of PMO  
- Standardization  
- Resource sharing  
- Project selection support

## Project Selection Methods
- Non-numeric: Sacred cow, operating necessity, competitive necessity, checklist  
- Numeric: NPV, IRR, payback period, opportunity cost  
- Time value of money

## Estimation Methods
- Top-down  
- Bottom-up  
- Parametric (ratio & apportion)  
- Duration formulas:  
  - Three-point estimate: (O + M + P) / 3  
  - Standard deviation: (P - O) / 6

- Critical path

- WBS hierarchy and work packages

## Change, Quality & Risk
- Change request process

- Risk vs. issue

## Earned Value Management
- EV, PV, AC

- CPI, SPI  
- Ahead/behind schedule  
- Over/under budget

- Predictive (waterfall)  
- Adaptive (agile)

- Formal acceptance
