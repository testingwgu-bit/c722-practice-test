# C722 Tag System

This file defines all tags used across the repository, including concepts, flashcards, and questions.  
Tags help with filtering, progress tracking, priority review, and building custom tests.

---

## 📌 Priority Tags
Use these to indicate how important a concept, flashcard, or question is for the OA.

- **#must-know** — Critical OA concepts; appear frequently; high priority.
- **#high-priority** — Same meaning as must‑know; used for flashcards/concepts.
- **#high-yield** — Medium priority; appears often but not as critical as must‑know.
- **#medium-priority** — Important but not core OA content.
- **#low-priority** — Good to know; rarely tested.

---

## 📌 Question Type Tags
Used to classify the nature of a question.

- **#scenario** — Scenario‑based question.
- **#math** — Requires calculation.
- **#critical-path** — Critical path or network diagram question.
- **#earned-value** — EV, PV, AC, CV, SV, CPI, SPI, EAC, ETC, TCPI.
- **#gantt-chart** — Gantt chart interpretation.
- **#definition** — Straight definition recall.
- **#diagram** — WBS, Gantt, network diagram, etc.

---

## 📌 Domain Tags (Aligned to C722 OA)
Use these to group questions or concepts by OA domain.

- **#domain1-project-concepts**
- **#domain2-project-life-cycle**
- **#domain3-selection-methods**
- **#domain4-methods**
- **#domain5-planning**
- **#domain6-time-management**
- **#domain7-execute-monitor-close**

---

## 📌 Review & Tracking Tags
These support progress tracking and custom test generation.

- **#flagged** — User flagged this item for review.
- **#missed** — User missed this question.
- **#review** — User wants to revisit this item.

---

## 📌 Additional Tags
General-purpose tags used across the repository.

- **#concept** — Used for concept explanations.
- **#flashcard** — Used for flashcard items.
- **#glossary** — Used for glossary definitions.

---

## Notes
- Priority tags (#must-know, #high-priority, #medium-priority, #low-priority) are used across concepts, flashcards, and questions.
- Questions may use #must-know and #high-yield instead of high/medium priority — this is intentional and consistent with OA terminology.
- Review tags (#flagged, #missed, #review) are used with progress tracking checkboxes.
