# C722 Project Management — Complete Study System

A fully structured, interactive study resource for the Western Governors University C722 Project Management OA.  
This repository includes:

- 76 OA‑style practice questions  
- Full Concepts reference guide  
- Flashcards (concepts + glossary)  
- Math problems  
- Critical path & Gantt chart practice  
- Earned value calculations  
- Progress tracking  
- Priority tagging  
- Ability to flag questions for review

## 🎯 How to Use This Study System

### **1. Start with Concepts**
Read through `/concepts/concepts.md` to learn all major topics:
- Triple constraint  
- Life cycle phases  
- Change, quality, and risk management  
- Organizational structures  
- Cost & duration estimation  
- Schedule compression  
- Critical path  
- Earned value  
- WBS  
- Gantt charts  

Each concept is tagged:
- `#must-know`
- `#medium-priority`
- `#low-priority`

---

### **2. Practice Questions**
Go to:

📁 `/questions/all-questions.md`

Each question includes:
- Answer  
- Explanation  
- Tags  
- Priority level  
- A checkbox to track mastery  
- A “Flag for Review” option  

Example:

```
- [ ] I know this
- [ ] I need to review this again
- [ ] Flag this question
```

You can filter questions by tags:
- `#must-know`
- `#scenario`
- `#math`
- `#critical-path`
- `#earned-value`
- `#gantt-chart`
